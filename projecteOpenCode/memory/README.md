# Memory

This folder contains curated project memory for larger models and long-running agents.

Memory is useful for orientation, but it must not replace reading the current files.

Use memory for:

- stable project conventions;
- recurring errors;
- reusable workflows;
- user preferences that are safe to store;
- summaries of completed sessions.

Do not store:

- API keys;
- passwords;
- private tokens;
- personal data that is not needed for the project;
- temporary state that should be verified instead.
