# Workflows

## Before starting

1. Read `AGENTS.md`.
2. Check `tasks/pending.md`.
3. Search memory only when prior project knowledge could help.
4. Read the relevant source files before editing.

## After finishing

1. Verify changed files.
2. Update `tasks/done.md` and `tasks/pending.md` if the task state changed.
3. Propose memory updates when a reusable lesson was learned.
