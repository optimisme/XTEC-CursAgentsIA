# Basic Frontend Design Skill

Use this skill when the user asks to improve the visual design, layout, consistency or user interface of a web project.

## Check

### Layout

- Use clear sections.
- Keep spacing consistent.
- Avoid crowded interfaces.
- Align related elements.

### Visual hierarchy

- Make the main title clearly visible.
- Use different sizes for title, section title and body text.
- Important actions should stand out.

### Consistency

- Reuse spacing, border radius, shadows and typography.
- Keep buttons visually consistent.
- Use the same style for repeated components.

### Colors

- Use a limited color palette.
- Ensure enough contrast.
- Do not rely only on color to communicate meaning.

### Components

- Cards, buttons, forms and navigation should follow the same visual language.

## Output

Return:

1. Visual issues found.
2. Suggested improvements.
3. Files to modify.
4. A short explanation of the design decisions.

## Rules

- Do not add CSS frameworks unless explicitly requested.
- Do not change the project architecture.
- Keep the design clean and maintainable.
