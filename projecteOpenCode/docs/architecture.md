# Architecture

This is a teaching project for OpenCode configuration examples.

The project demonstrates:

- project-level instructions in `AGENTS.md`;
- agents in `.opencode/agents/`;
- reusable commands in `.opencode/commands/`;
- skills in `.opencode/skills/`;
- local MCP servers in `.opencode/mcp/`;
- optional long-term memory in `memory/`.

Example app files usually follow this structure:

```text
index.html
styles.css
app.js
```

For one-file HTML exercises, CSS and JavaScript can stay inside the requested `.html` file.
