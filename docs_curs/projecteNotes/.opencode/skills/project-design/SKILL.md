# Project Design Skill

Apply the following principles when improving the visual design of any interface, page, or user-facing output:

## Principles

1. **Simple layout** — Keep the layout clear and uncluttered. Avoid unnecessary borders, decorations, or visual noise.
2. **Generous spacing** — Use enough whitespace between elements (padding, margins, gaps) so content breathes and is easy to scan.
3. **Readable typography** — Use font sizes of at least 16px for body text. Ensure sufficient line-height (1.5+) and contrast against the background.
4. **Clear buttons** — Make buttons large enough to tap or click easily (minimum 44x44px tap target). Use distinct background colors and hover/focus states.
5. **Consistent colors** — Use a minimal, consistent color palette. Limit primary actions to one accent color. Ensure sufficient contrast for accessibility (WCAG AA).
