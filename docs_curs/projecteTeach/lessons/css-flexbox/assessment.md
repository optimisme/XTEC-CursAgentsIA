# Assessment: CSS Flexbox

## Assessment Criteria

- The student identifies the flex container and flex items.
- The student applies `display: flex` to the correct element.
- The student uses `justify-content` and `align-items` intentionally.
- The student explains how `flex-direction` changes the main axis.
- The final layout matches the requested arrangement.

## Observable Evidence

- The student's CSS contains a valid flex container.
- The direct child elements are arranged as expected.
- The student can predict the effect of changing alignment properties.
- The student can describe why a property did or did not affect the layout.

## Minimum Achievement Level

The student builds a horizontal row of items with `display: flex` and uses one alignment property correctly.

## Extension Achievement Level

The student creates a responsive layout that changes direction or spacing and explains the main axis in both states.
