# Projecte final · «Lliuraments»

El projecte final **no és feina nova**: és un **recull de les vuit tasques** del curs (T1–T8) en un sol arxiu **PDF**, amb una valoració teva del curs al principi. No cal crear cap repositori nou ni programar res més. Si has fet alguna ampliació opcional, també la hi pots posar.

**L'avaluació del curs es fa a partir d'aquest document.**

## Què has de lliurar

Un únic arxiu PDF amb aquestes dues parts.

### 1. Explicació inicial i valoració del curs

Una pàgina, com a màxim dues, escrita per tu (no per l'agent):

- Què has après i què t'ha sorprès de treballar amb agents.
- Què t'ha costat més i per què: el model, el context o la manera de definir les tasques.
- Què faràs servir a les teves classes o a la teva feina, i què no.
- Què canviaries del curs.

### 2. Recull de les tasques

Un apartat per a cada tasca, de mitja pàgina a una pàgina:

| Què hi poses | Detall |
|---|---|
| Enllaç | L'etiqueta de la tasca al repositori `lliuraments` (`https://github.com/<usuari>/lliuraments/tree/t1` … `t8`) i, a la T5, el full de Google Sheets |
| Què has fet | Dues o tres frases amb les teves paraules |
| Evidència | Una captura o un fragment curt: la web, la sortida de `npm test`, la resposta de la CLI, les issues, `PLAN.md`… |
| Dificultats | Què ha fallat i com ho has resolt, o fins on has arribat |

Si una tasca no l'has pogut acabar, inclou-la igualment: explica fins on has arribat i on t'has encallat.

| Tasca | Tema | Què s'hi feia |
|---|---|---|
| T1 | [01 · Agents IA i OpenCode](01%20-%20Agents%20IA%20i%20OpenCode.md) | Repositori, `opencode.json` i pla del projecte |
| T2 | [02 · Harness Engineering](02%20-%20Harness%20Engineering.md) | Arnès SDD i una tasca validada amb tests |
| T3 | [03 · Function calling i models locals](03%20-%20Function%20calling%20i%20models%20locals.md) | Una funció del projecte a la CLI amb function calling |
| T4 | [04 · MCPs GitHub, Playwright i MCP propi](04%20-%20MCPs%20GitHub,%20Playwright%20i%20MCP%20propi.md) | Una issue a GitHub i una captura amb Playwright |
| T5 | [05 · Serveis de Google per a agents](05%20-%20Serveis%20de%20Google%20per%20a%20agents.md) | Resum per alumne en un full de Google Sheets |
| T6 | [06 · RAGs i serveis de dades](06%20-%20RAGs%20i%20serveis%20de%20dades.md) | Normativa al RAG local, amb la font citada |
| T7 | [07 · ATD i treball autònom](07%20-%20ATD%20i%20treball%20autònom.md) | Una tasca en Markdown amb `/next-md-task` |
| T8 | [08 · Servidors d'inferència](08%20-%20Servidors%20d'inferència.md) | Comparativa de models i servidors |

## Com fer el PDF

Escriu-lo amb l'eina que vulguis (Google Docs, Word, Markdown…) i exporta'l a PDF. Si vols, demana a l'agent un primer esborrany del recull a partir dels repositoris, i revisa'l: la valoració inicial i l'apartat de dificultats han de ser teus.

Abans de lliurar-lo, comprova que:

- [ ] Els enllaços als repositoris funcionen i el professor hi té accés.
- [ ] Les captures no mostren cap clau, token ni dada personal.
- [ ] El PDF té la valoració inicial i un apartat per a cada tasca.
