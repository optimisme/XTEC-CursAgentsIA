# Assessment: Introduccio a MongoDB

## Assessment Criteria

- The student explains MongoDB as a document database.
- The student distinguishes database, collection, document, and field.
- The student writes a valid `insertOne` command for a simple document.
- The student writes a valid `find` query.
- The student explains what a basic filter does.

## Observable Evidence

- The student's explanation uses the terms database, collection, and document correctly.
- The inserted document has clear fields and valid object structure.
- The student's query returns the expected set of documents.
- The student can explain why a filtered query returns fewer documents than `find()`.

## Minimum Achievement Level

The student inserts one valid document and reads documents from the collection with `find()`.

## Extension Achievement Level

The student inserts multiple documents, uses a meaningful filter, and explains how MongoDB document structure differs from a fixed SQL table.
