# Exercises: CSS Flexbox

## Basic Exercise

Create a container with three boxes and place them in a horizontal row using Flexbox.

## Guided Exercise

1. Create a `div` with class `toolbar`.
2. Add three child buttons or links inside it.
3. Apply `display: flex` to `.toolbar`.
4. Use `justify-content: space-between`.
5. Use `align-items: center`.
6. Give the toolbar a fixed height so the vertical alignment is visible.

## Optional Extension

Add a media query so the toolbar becomes a vertical column on narrow screens.

## Expected Result

The direct children of the container are arranged with Flexbox. The student can change spacing and alignment by modifying `justify-content`, `align-items`, and `flex-direction`.
