# Exercises: Esdeveniments en JavaScript

## Basic Exercise

Create a button and a paragraph. When the button is clicked, change the paragraph text to `Has fet clic al boto`.

## Guided Exercise

1. Add a button with the text `Canvia missatge`.
2. Add a paragraph with an initial message.
3. Select both elements with `document.querySelector`.
4. Add a `click` event listener to the button.
5. Inside the listener, update the paragraph text.
6. Add a second line that logs `event.target` to the console.

## Optional Extension

Add two buttons. Each button should write a different message into the same paragraph.

## Expected Result

The page reacts only when the user clicks a button. The paragraph text changes, and the console shows which button received the click.
