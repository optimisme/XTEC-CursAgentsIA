# Assessment: Esdeveniments en JavaScript

## Assessment Criteria

- The student can explain an event in simple terms.
- The student attaches a listener with `addEventListener`.
- The student passes a function reference correctly.
- The student can use or describe the event object.
- The practical exercise runs after a user action.

## Observable Evidence

- The student answers checking questions correctly.
- The student's code uses a selected DOM element.
- The student's code includes a working `click` listener.
- The student's explanation distinguishes defining a listener from running a function immediately.

## Minimum Achievement Level

The student creates one working button interaction with `addEventListener` and explains why the handler runs after the click.

## Extension Achievement Level

The student handles more than one button, uses `event.target`, and explains how the event object helps identify the source of the action.
